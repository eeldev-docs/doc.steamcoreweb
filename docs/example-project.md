# Example Project

## Blueprint Example Project
You can download the example project from GitHub:

- [Download Example Project](https://github.com/eeldev-ue4/SteamCoreWeb_Example/releases)

The example project shows the [microtransaction](/docfiles/examples/microtransactions), [leaderboard](/docfiles/examples/leaderboards) and [friends list](/docfiles/examples/friends) flows from this documentation. Set your own publisher key and App ID in Project Settings before you run it, see [Configuring the Plugin](/docfiles/getting_started/configuring-plugin).
